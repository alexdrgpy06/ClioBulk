## 2024-05-24 - Arbitrary File Read/Write Prevention
**Vulnerability:** The application allowed arbitrary file reads and writes because Tauri v2 filesystem scopes (`is_allowed`) only check if a path is within an allowed directory, not the file type. The `capabilities/default.json` additionally contained overly permissive `fs:allow-read` and `fs:allow-write` strings.
**Learning:** Checking `is_allowed` against `fs_scope` is insufficient for file-processing APIs; malicious actors could read or overwrite configuration files, sensitive documents, or system files if they are within the scoped directory. Furthermore, Tauri v2 requires specific object structures to scope generic string permissions securely.
**Prevention:** Always restrict generic string permissions (like `fs:allow-read`) in `capabilities.json` with specific scoped path patterns (e.g., `$PICTURE/**`). Furthermore, explicitly implement strict file extension whitelisting on all input and output paths directly within the command implementation logic.
