## 2024-07-26 - Arbitrary File Write Prevention via Explicit Extension Validation
**Vulnerability:** The application saves image files based on paths constructed dynamically, but relied on the underlying `image` library to determine the file format from the extension. If the output extension was not explicitly verified against a safe whitelist (e.g., .jpg, .png, .webp), an attacker could potentially trick the app into writing other file formats or writing to unauthorized paths if extension inferences failed or paths were manipulated.
**Learning:** We must not solely rely on the internal format inferences of generic libraries to determine safe output types when generating files. Explicit validation is necessary at the application boundary before any disk write operation occurs.
**Prevention:** To prevent arbitrary file writes when generating files, explicitly validate and strictly whitelist output file extensions against safe formats (e.g., .jpg, .png, .webp) before attempting to save.
