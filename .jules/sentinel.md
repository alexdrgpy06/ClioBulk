
## 2026-04-04 - Prevent Arbitrary File Writes via Path Extension Whitelisting
**Vulnerability:** The application relied solely on Tauri's `fs_scope` for file write validation in the native backend, which does not restrict file extensions. This could allow arbitrary file writes (e.g., executing scripts or overwriting configuration files) if the user selects a non-image file type in the save dialog.
**Learning:** Relying solely on sandbox or scope boundaries for security is insufficient if the data being written is untrusted or unverified.
**Prevention:** Always implement explicit file extension whitelisting on user-provided output paths, even if the directory itself is allowed by the security sandbox. Ensure that extensions match the expected file types generated by the application.
