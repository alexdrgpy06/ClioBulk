## 2025-04-06 - Bypassing React Renders for Progress Updates
**Learning:** High-frequency Zustand state updates (like a progress bar updating from 0 to 100 repeatedly) can cause severe performance degradation if the React component is subscribed to the specific state property, as it triggers a full React render cycle for every tick.
**Action:** Use `useStore.subscribe` in combination with a DOM `useRef` to manually update the DOM element's style, bypassing React entirely. Crucially, ensure the React component *does not* select the high-frequency state via `useStore((state) => state.progress)` or `useShallow`, otherwise it will still re-render despite the `useRef` optimization. Synchronize initial state using `useStore.getState().progress` before subscribing to prevent UI desyncs.
