## 2024-05-14 - Bypassing React renders for high-frequency progress updates in Zustand v4
**Learning:** In Zustand v4, when not using subscribeWithSelector, useStore.subscribe listens to the entire state object. When trying to optimize high-frequency state updates like progress bars by bypassing React renders, simply removing the prop from the useStore hook isn't enough; the store subscription must also be manually synchronized. Without manually reading the initial state (useStore.getState()) and manually checking previous vs current values within the subscribe callback, desyncs and redundant DOM updates occur.
**Action:** When implementing bypass-render optimizations for high-frequency Zustand state, always manually read initial state in useEffect, store the current value locally, and explicitly diff the incoming state against the local value within the subscription callback before manipulating the DOM.
