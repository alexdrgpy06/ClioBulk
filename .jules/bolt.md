## 2024-05-24 - Bypass React renders for high-frequency progress updates
**Learning:** In a React application using Zustand, subscribing a component to a rapidly changing state value (like a progress percentage that updates hundreds of times per second) causes massive performance overhead due to continuous re-renders and virtual DOM diffing.
**Action:** For high-frequency, simple DOM updates (like a progress bar's width), use `useStore.subscribe()` inside a `useEffect` alongside a `useRef` to mutate the DOM element's style directly. This bypasses the React render cycle entirely, transforming O(N) VDOM reconciliation into O(1) direct DOM mutation, significantly improving performance and preventing the main thread from blocking. Always remember to sync the initial state before subscription to avoid visual jumping if the component mounts mid-process.
