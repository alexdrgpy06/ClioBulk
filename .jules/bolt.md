## 2024-05-18 - [Optimizing High-Frequency Zustand Updates]
**Learning:** Bypassing React renders using `useStore.subscribe` combined with a `useRef` directly on the DOM node is highly effective for fast-changing states like progress bars. However, when doing so, it's critical to avoid destructuring the high-frequency state (e.g. `progress`) inside the component body, as that will still trigger re-renders. We also need to manually handle initial state syncing and state comparison `state.progress !== prevState.progress` inside the subscribe callback.
**Action:** When implementing progress bars or other high-frequency updating elements, use `useRef` combined with manual `useStore.subscribe` and explicitly ensure the component only subscribes to boolean state (like `processing`) while leaving the rapid updates strictly to the DOM node manipulation.
