## 2024-04-04 - [Optimization] Bypassing React renders for high-frequency state updates
**Learning:** When using `useStore.subscribe` and a `useRef` (e.g., for a progress bar) to bypass React renders for high-frequency state updates, the component's `useStore` hook must not subscribe to the high-frequency state property. Also, in Zustand v4 setups where `subscribeWithSelector` is not used during store creation, `useStore.subscribe` listens to the entire state object, so you must manually compare the current and previous state within the subscribe callback to avoid redundant DOM updates.
**Action:** When implementing high-frequency progress indicators, remove the property from the React hook subscription array, manually sync initial DOM state using `useStore.getState()` within the `useEffect` before setting up the subscription, and explicitly check `state.prop !== prevState.prop` inside the subscriber function.
