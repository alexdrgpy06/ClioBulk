## 2024-04-09 - Bypassing React renders for high-frequency Zustand state updates
**Learning:** In Zustand v4 setups without `subscribeWithSelector`, `useStore.subscribe` listens to the entire state object. When bypassing React renders for high-frequency state updates like progress bars via `useStore.subscribe` and a DOM `useRef`, you must manually compare the current and previous state within the subscribe callback to avoid redundant DOM updates. Furthermore, you must ensure the component's `useStore` hook does not subscribe to the high-frequency state property to prevent unnecessary React re-renders. Lastly, explicitly synchronize the initial state by reading `useStore.getState()` and updating the ref's properties within the `useEffect` hook prior to establishing the subscription to ensure correct initial display.
**Action:** Remove the high-frequency property from the `useStore` selector, use a `useRef` for the DOM element, subscribe manually with `useEffect`, manually compare current/previous state in the callback before updating the DOM ref, and initialize the DOM ref's state before setting up the subscription.
