## 2025-02-28 - Optimizing High-Frequency Progress Bar Updates with Zustand
**Learning:** In Zustand v4 setups where `subscribeWithSelector` is not used, `useStore.subscribe` listens to the entire state object. When using `useStore.subscribe` alongside a `useRef` to bypass React renders for high-frequency progress updates, it is crucial to ensure the React component's `useStore` hook only subscribes to the properties needed for mounting/unmounting (like `processing`) and does not subscribe to the high-frequency `progress` property. Manually comparing `state.progress !== prevState.progress` within the subscribe callback correctly avoids redundant DOM updates. Also, it is vital to synchronize the initial state within the `useEffect` hook prior to establishing the subscription by reading `useStore.getState()`.
**Action:** Always verify that components bypassing renders for high-frequency updates don't accidentally subscribe to the high-frequency state via `useStore` hooks, explicitly check for differences in the vanilla subscription callback, and remember to sync the initial state using `useStore.getState()` on mount.
