## 2024-04-16 - Bypassing React renders for high-frequency Zustand state updates
**Learning:** In Zustand v4 setups where `subscribeWithSelector` is not used during store creation, `useStore.subscribe` listens to the entire state object. If you bypass React renders using `useStore.subscribe` and a `useRef` (e.g., for a progress bar), ensure the component's `useStore` hook does NOT subscribe to that high-frequency state property. Also, explicitly synchronize the initial state by reading `useStore.getState()` in `useEffect` and manually compare current/previous state within the subscription callback.
**Action:** When optimizing high-frequency state updates in Zustand (like progress bars or sliders), use `useRef` and `useStore.subscribe`. Remove the high-frequency property from the main component's `useStore` hook to prevent the React render cycle, read the initial value manually in `useEffect`, and compare changes manually in the subscribe callback.
