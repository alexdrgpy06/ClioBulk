## 2024-06-25 - Bypassing React Renders for Zustand High-Frequency Updates
**Learning:** In Zustand v4, when `subscribeWithSelector` is not used, `useStore.subscribe` listens to the entire state object. When bypassing React renders to update DOM directly for high-frequency properties (like `progress`), it's critical to manually track and compare the previous and current values within the subscription callback to prevent redundant DOM updates. Furthermore, the component's `useStore` hook must omit the high-frequency property from its dependency array to effectively prevent unnecessary re-renders. Lastly, initial state must be synchronized explicitly via `useStore.getState()` inside `useEffect` to prevent UI desyncs upon mount.
**Action:** When optimizing high-frequency state updates in Zustand v4 without selectors, always remove the property from the `useStore` dependency array, implement manual diffing within the `.subscribe()` callback, and explicitly synchronize the initial state to the DOM ref.
