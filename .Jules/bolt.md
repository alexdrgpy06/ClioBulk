## 2024-04-24 - Bypass React renders for high-frequency Zustand progress updates
**Learning:** Subscribing a React component to a rapidly changing Zustand property (like a progress bar updating from a native backend or worker loop) triggers severe re-rendering bottlenecks. In Zustand v4 without subscribeWithSelector, useStore.subscribe listens to the entire state object.
**Action:** Extract the rapidly changing property from the React useStore hook dependencies. Instead, use a `useRef` to directly manipulate the DOM element inside a `useEffect` that manually subscribes to the store via `useStore.subscribe`, ensuring you manually check if the specific property changed (`state.progress !== prevState?.progress`). Always remember to synchronize the initial state inside the effect by reading `useStore.getState().progress`.
