## 2024-03-20 - High-Frequency Zustand Updates Bypassing React
**Learning:** In Zustand v4 without `subscribeWithSelector`, `useStore.subscribe` listens to the entire state object. When bypassing React renders for high-frequency state updates (like a progress bar) using a `useRef`, you must not include the high-frequency property in the component's `useStore` hook, or it will still trigger unnecessary re-renders. Also, explicit synchronization of the initial state (`useStore.getState()`) and manual comparison within the subscription callback are required.
**Action:** When animating or updating progress bars, decouple the fast-changing value from React state. Subscribe directly to the store and mutate DOM elements via refs, explicitly comparing current and previous states manually if `subscribeWithSelector` is absent.
