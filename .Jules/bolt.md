## 2024-04-11 - Zustand High-Frequency State Rendering Bypass
**Learning:** When bypassing React renders for high-frequency state updates using `useStore.subscribe` and a `useRef` (e.g., for a progress bar), if the component's `useStore` hook still subscribes to the high-frequency state property (either directly or via `useShallow`), it will trigger unnecessary re-renders, defeating the optimization. In Zustand setups without `subscribeWithSelector`, `useStore.subscribe` listens to the entire state object, so one must manually synchronize initial state via `useStore.getState()` and compare current/previous state within the subscription callback to prevent UI desyncs or redundant DOM updates.
**Action:** Always ensure the component's `useStore` hook exclusively selects properties that *should* trigger a re-render (e.g., `processing`), and implement manual state diffing within `useStore.subscribe` to directly mutate the DOM via `useRef` for high-frequency state properties.
