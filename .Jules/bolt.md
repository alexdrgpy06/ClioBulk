## 2024-05-17 - Fast Lookup Dictionaries in Zustand State
**Learning:** In ClioBulk, to optimize O(N) searches inside loops or high-frequency event listeners (like `process-progress` progress updates), implementing a pre-computed lookup dictionary reduces complexity to O(1). However, dynamically rebuilding this dictionary inside the hot path or using `useMemo`/`useEffect` tied to a rapidly changing global state array (like `files`) causes severe performance regressions worse than the original `Array.find()`.
**Action:** Always maintain the O(1) dictionary directly within the Zustand store state alongside the primary list. Mutate the dictionary strictly during infrequent list-modification actions (`addFiles`, `removeFile`, `clearFiles`) to ensure it's pre-computed and incurs zero penalty during high-frequency events.
